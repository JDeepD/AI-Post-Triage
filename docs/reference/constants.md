# `wp-config.php` Constants

| Constant                       | Description                                                                           |
| ------------------------------ | ------------------------------------------------------------------------------------- |
| `WIRE_DESK_ENCRYPTION_KEY`     | Used to encrypt/decrypt data before storing in the database.                          |
| `WIRE_DESK_OPENROUTER_API_KEY` | OpenRouter API key. Takes precedence over the key saved for the OpenRouter connector. |
